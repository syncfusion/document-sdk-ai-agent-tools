# Document Processing AI Agent Applications - Console Examples

This directory contains example applications that demonstrate how to build intelligent document processing solutions using the Syncfusion Agent Library and Microsoft Agent Framework. These projects showcase practical implementations of AI-powered agents for document operations and content generation. Each example demonstrates different use cases and patterns for building agent-driven applications.


### [AgentChatConsole](./AgentChatConsole/)

A command-line application that demonstrates intelligent document processing using AI. Built with .NET and powered by OpenAI and Syncfusion Agent tools, it provides an interactive terminal interface for autonomous document operations including creation, conversion, and processing across multiple formats (.docx, .xlsx, .pdf, .pptx, and more).


### [BlogGenerator](./BlogGenerator/)

A command-line application that automatically generates rich, styled blog posts with AI-generated content and images. Built with .NET and powered by OpenAI and Syncfusion Agent tools, it creates complete blog posts in both HTML and Word formats through an interactive multi-phase workflow, including AI-generated titles, structured outlines, professionally styled content, and AI-generated images with captions.


### [AutomatedPDFRedaction](./AutomatedPDFRedaction/)

A command-line application that demonstrates intelligent automated PDF redaction using AI. Built with .NET and powered by OpenAI and Syncfusion PDF Agent tools, it integrates with the Microsoft Agent Framework to autonomously detect and redact sensitive information from PDF documents. The application analyzes PDF content, identifies personally identifiable information (PII) such as names, email addresses, phone numbers, and other sensitive data, then permanently redacts them with black boxes through an interactive terminal interface.
